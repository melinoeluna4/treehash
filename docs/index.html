A deterministic fingerprint

treehash

Un árbol de archivos no es una carpeta: es una huella. treehash la convierte en un SHA-256 estable para cache keys, manifiestos y comprobaciones de “¿cambió algo?”.

SHA-256 9c1d8f0e4b4f7c3b deterministic
Leer el repositorio →

Qué es

Una CLI pequeña que recorre un directorio, ordena sus archivos regulares y combina sus hashes con las rutas relativas. El resultado es una huella que no depende del orden del sistema de archivos.

Sin dependencias externas. Un binario de Go que puedes instalar con go install y ejecutar en cualquier runner.

Por qué existe

Una marca de tiempo no es una cache key. Un commit no siempre basta cuando el build depende de archivos generados. treehash responde a la pregunta aburrida y necesaria: ¿este árbol es el mismo que el de la última vez?

El manifiesto

Archivos → hashes → un solo número

El orden de recorrido no importa. El contenido y la ruta sí.

src/
├── main.go          6f2a…
├── run.go           a91c…
└── run_test.go      44be…
README.md            0d7f…

manifest = sort(path + hash)
treehash = sha256(manifest)

Uso

Una huella en la terminal

Por defecto hashea el directorio actual y omite .git, node_modules y dist.

treehash
9c1d8f0e…  .  (42 files)

Notas al margen

Tres decisiones

  1. La ruta relativa entra en el manifiesto: renombrar cambia el hash.
  2. Solo se hashean archivos regulares; symlinks y dispositivos se omiten.
  3. Se ordena antes de combinar para que el walker no altere el resultado.
